GPX Incline Adjuster

Flattens descents to 0%, caps climbs at your treadmill's max, and holds each whole-percent incline change to a minimum distance — so the treadmill is never asked to change incline faster than once every few seconds, no matter how choppy the source elevation data is. Optionally splits a long route into standalone files of a set mileage, one per treadmill session.
